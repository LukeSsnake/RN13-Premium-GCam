# 📱 RN13 Premium GCam ✨

Configuração GCam Premium desenvolvida e otimizada por Lukes especificamente para o Redmi Note 13 4G.

O objetivo desta configuração é proporcionar uma imagem mais refinada, com aparência premium, cores vivas e naturais, HDR equilibrado, boa faixa dinâmica e maior consistência entre as câmeras.

# 📱 Dispositivo

- Modelo: Redmi Note 13 4G
- Android: Android 15
- HyperOS: HyperOS 2
- GCam: SGCAM 8.4.400.42 XXX STABLE V43

# 📷 Câmeras

- Principal: Samsung HM6 — 108 MP
- Ultra-wide: GalaxyCore — 16 MP
- Macro/tele: Samsung — 8 MP
- Auxiliar: SmartSens — 2 MP
- Frontal: otimizada para o sensor frontal do Redmi Note 13 4G

# ✨ Características da configuração

- Cores vivas e equilibradas
- Aparência inspirada em câmeras premium
- HDR ajustado
- Melhor equilíbrio de contraste
- White Balance personalizado
- Maior consistência de cores entre câmera principal e ultra-wide
- Ajustes específicos de nitidez e redução de ruído
- Otimização da câmera frontal
- Configuração ajustada para fotos diurnas e diferentes condições de iluminação

# 📥 Instalação

1. Instale a versão SGCAM 8.4.400.42 XXX STABLE V43.
2. Baixe o arquivo "📱RN13_Premium✨.xml".
3. Coloque o XML na pasta de configurações da GCam.
4. Abra a GCam e carregue o XML.
5. Reinicie a GCam após aplicar a configuração.

# ⚠️ Importante

Esta configuração foi desenvolvida especificamente para o Redmi Note 13 4G e para a versão indicada da SGCAM.

O resultado pode variar em outros aparelhos, sensores ou versões da GCam.
